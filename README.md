
# Voiceprint



A psychological horror game where the monster hunts you using your own voice — cloned in real-time by ElevenLabs.



🎮 **Play live:** [voiceprint-alpha.vercel.app](https://voiceprint-alpha.vercel.app/)



## The mechanic



Halfway through the game, you're asked to speak into your microphone for 15 seconds. ElevenLabs clones your voice instantly. Then the monster starts whispering at you in the dark — in your own voice.



## Built with



- **Zed** — entire codebase written in Zed using the AI agent panel

- **ElevenLabs** — 5 APIs:

  - Instant Voice Cloning (the killer mechanic)

  - Text-to-Speech (Cedric narrator)

  - Sound Effects API (ambient drone, footsteps, monster sounds)

  - Music API (trailer soundtrack)

- **Three.js** — 3D rendering

- **Vite + TypeScript** — frontend

- **Vercel** — deployment + serverless functions for API key safety
